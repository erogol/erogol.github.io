Independent CPU text-to-speech measurements · Last tested 2026-11-11

Small open-weight TTS models on CPU

Twelve models. Five English texts. One and four CPU threads. Compare speed, first-audio latency, memory, intelligibility, and audio.

Host: AMD EPYC Rome, 16 cores, AVX2, no AVX-512, no AMX, no GPU. Speed run: 13:12–13:37 UTC. WER run: 13:38–13:49 UTC.

Recommendation: Phonon 31M

Use Phonon 31M with the ptts runtime (Apache-2.0) for live CPU voice.

  • It streams. Median first audio is 82 ms at 1 thread (max 97 ms), against 286 ms for Pocket TTS. At 4 threads it is 43 ms.
  • It is 3.2× faster than Pocket TTS at 1 thread (RTF 0.252 against 0.813).
  • Its WER is 1.6%, the lowest among streaming models. Peak memory is 363 MB, against 1347 MB for Pocket TTS. It does not require PyTorch.

Fast alternative: SupraTTS-1.0-Preview (MIT, 1.03M parameters). It has RTF 0.014 (74× real time) at 1 thread and median first audio of 85 ms. It does not stream. WER is 4.1%; it dropped “3:45”. Peak memory is 641 MB. First audio grows with the first sentence.

Streaming runner-up: Linnet en-35m. First audio is 70 ms, RTF 0.188, and peak memory 187 MB. Its weights license is not open source. WER is 4.1%. It has no text normalization.

Not for live voice: Klein has 0.0% WER and RTF 0.160, but no streaming: first audio is 860 ms (max 1831 ms). Paradee has 0.0% WER and RTF 0.048, but first audio waits for a sentence (max 525 ms). Sopro streams, but its RTF is 1.76 at 1 thread and 1.36 at 4 threads. Inflect has the highest WER (6.5%). Silencio base has RTF 0.83. Woof has a non-commercial license. Mach Boom uses the least memory (107 MB), but reaches only 2.5× real time.

Excluded: audio8-TTS-0.1B-ONNX-INT8 did not stop on English text. Whisper found no intelligible speech. See Method.

Listen before you decide. This benchmark does not rate sound quality. WER measures only word intelligibility for these samples.

Metric key

RTF
Compute time ÷ audio length. Lower is better. 0.25 means 4× real time.
TTFA
Time from the call to the first audio chunk. Median across five texts.
Peak memory
Peak resident memory of the full process at 1 thread.
WER
Whisper large-v3 word error rate. Lower is better. Intelligibility only.

A “3.45” transcript for “3:45” adds 0.1 to the numbers-sentence WER. A WER near 1.6% can therefore be a correct reading.

Method

  • All 12 models ran one at a time on 2026-11-11. Each model used a separate process and Python environment. Loaders used local model files.
  • Each process loaded the model and ran one warm-up. It ran each text three times. The tables show the median.
  • OMP, OpenBLAS, MKL, and runtime threads were set to 1 or 4. The test included model loading, splitting, and synthesis.
  • Streaming models used their streaming API. Other models produced one sentence or piece at a time. Their TTFA includes the first full sentence or piece.
  • Each model used one fixed built-in voice. Sopro cloned the Pocket “anna” long sample from run 2 (18.7 s). Sopro used fp32. Its optional CPU int8 mode was not tested.
  • Supra omitted the short inter-sentence pause that its standard synthesis function adds. Linnet used a 600-frame limit instead of its 300-frame default.
  • For the seven earlier models, run 3 RTF and TTFA changed less than 20% from run 2. The largest change was Linnet RTF at 1 thread: 0.225 to 0.188. WER did not change.
  • audio8 was excluded. Its runtime was https://github.com/Audio8-AI/Audio8_TTS at commit 1d64afc. Its packaged default voice gave no output in 900 seconds at 1 thread. At 4 threads it made 700 frames and 32.5 seconds of audio for a 2-second text. Whisper heard no words. English reference tests gave noise or silence. The runtime CLI made 11.9 seconds of audio; Whisper heard only “now”. The source archive includes the full record.
  • Release dates are Hugging Face repository creation dates. Parameters and licenses come from model cards and the Hugging Face API. These are metadata, not benchmark measurements.
