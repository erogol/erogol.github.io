Method and data
  • Host: see Test machine.
  • 12 models ran one at a time on 2026-11-11. tiny-voca and nano-edge-tts were added on 2026-11-16 and ran alone with the same harness and settings. Each model used a separate process and Python environment, with local model files.
  • Each process loaded the model and ran one warm-up. Then it ran each text three times. The tables show the median.
  • OMP, OpenBLAS, MKL, and runtime threads were set to 1 or 4. The test included model loading, splitting, and synthesis.
  • Streaming models used their streaming API. Other models produced one sentence or piece at a time. Their first audio includes the first full sentence or piece.
  • Each model used one fixed built-in voice. Sopro cloned the Pocket “anna” sample (18.7 s) and used fp32. Its optional CPU int8 mode was not tested.
  • Supra omitted the short pause that its standard synthesis function adds between sentences. Linnet used a 600-frame limit instead of its 300-frame default.
  • A “3.45” transcript for “3:45” counts as an error. It adds 0.1 to the numbers-text WER, so a WER near 1.6% can be a correct reading.
  • For the seven models from run 2, run 3 RTF and first audio changed less than 20%. WER did not change.
  • Run 4 (2026-11-20) added 5 rows from the Hugging Face TTS leaderboard with the same harness: PiVo-1.4M, Supertonic 3, Inflect-Micro-v3, Underdog Woof with its Mira voice, and Scylla’s Band. The 1-minute load average was 4 or less before each timing run. UTMOS was scored for all models after the timing runs.
  • SmollerTTS was added on 2026-11-19 and ran alone with the same harness. It used its release at commit c046ac7: the three ONNX graphs on onnxruntime with graph optimizations off, and the release JavaScript text frontend on Node. Natural controls, one frontend chunk at a time.
  • kale-tts-1-nano was added on 2026-11-20 and ran alone with the same harness. It used its release at commit b6ce188: the int8 ONNX file on onnxruntime through the release Python runtime, and the release JavaScript text frontend on Node. Voice kenzie, one sentence at a time.
  • Dropped in run 4 (a model stays only if its 1-thread RTF is below 1.0): Kokoro-82M (RTF 1.16 on 1 thread), Inflect-Mini-v3 (RTF 1.02 on 1 thread), steer-tts-edge (gated download).
  • Excluded: audio8-TTS-0.1B-ONNX-INT8 (runtime https://github.com/Audio8-AI/Audio8_TTS at commit 1d64afc). On English text it did not stop, and Whisper found no words in its output. The source archive has the full record.
  • Release dates are Hugging Face repository creation dates. Parameters and licenses come from model cards and the Hugging Face API.
  • Runtimes: ptts 0.7.0, linnet-tts 0.2.0, kleintts 0.1.0, sopro 2.2.0, LinnetTTS, Paradee, tiny-voca (voice F2, one sentence at a time), nano-edge-tts at commit 37b4935 with kokoro 0.9.4 (voice af_heart, one sentence at a time), PiVo at 515d84f (voice Pi), supertonic 1.3.1 (voice F1), Inflect-Micro-v3 at 077eac5 (voice cassidy), scyllasband at 1b8482f with the LiteRT bundle v4-20261106-apple (voice scylla). New non-streaming models produced one sentence at a time.
